# Раскладка управления (как в Bedrock)

Сенсорные кнопки — это раскладка лаунчера (Zalith 2 умеет джойстик внутри раскладки
с версии 2.4.11). Её один раз собирают в редакторе раскладок Zalith по этой схеме,
экспортируют и кладут в `overlay/assets/serverpack/default_layout.json` —
лаунчер ставит её по умолчанию, а в меню редактора её можно не показывать.

```
┌───────────────────────────────────────────────────────────┐
│ [II]          [💬][↻ /cmd][🎤]                     [M] [👁] │  ← верх
│                ┌─────────────┐                             │
│                │  чат 4–5    │                             │
│                │  строк      │                             │
│                └─────────────┘                             │
│                                                           │
│                   свайп — обзор                          │
│        тап — поставить / использовать                    │
│        удержание — ломать / бить                         │
│                                                           │
│   [⇧]                                            [Q]      │
│   ( ◯ )  джойстик                          [⇩]   [ ⬆ ]    │
│  (     )                               [⋯]                │
│                   ▭▭▭▭▭▭▭▭▭ хотбар (тап)                  │
└───────────────────────────────────────────────────────────┘
```

| Кнопка | Где | Отправляет | Режим |
|---|---|---|---|
| Джойстик | слева снизу | W/A/S/D | до упора вперёд — бег (Ctrl), если версия Zalith это поддерживает, иначе отдельная кнопка ⇧ над джойстиком |
| ⬆ Прыжок | справа снизу, крупная | Space | удержание; в воде — всплыть |
| ⇩ Присесть | слева от прыжка | Left Shift | **переключатель**, как в Bedrock |
| ⋯ Инвентарь | справа у хотбара | E | нажатие |
| Q | над прыжком, маленькая | Q | нажатие — выбросить предмет |
| II Пауза | слева сверху | Esc | нажатие |
| 💬 Чат | слева от чата | T | нажатие |
| ↻ Повтор команды | справа от чата | **F13** | нажатие — мод MobileCraft отправит последнюю команду |
| 🎤 Микрофон | справа от ↻ | **F14** | нажатие — мод включает/выключает микрофон; пока включён, у чата мигает красное «MIC» |
| M | справа сверху | M | меню Litematica |
| 👁 | справа сверху | F5 | смена вида |

Жесты лаунчера (настройки Zalith → управление):
- свайп по свободной части экрана — поворот камеры;
- короткий тап — правая кнопка мыши (поставить блок, использовать);
- долгое нажатие (~300 мс) — левая кнопка (ломать, атаковать);
- тап по хотбару — выбор слота (встроено в PojavLauncher).

Кнопки F13 и F14 физически на клавиатуре телефона нет, поэтому они никогда не
сработают случайно и ни с чем в игре не конфликтуют.
