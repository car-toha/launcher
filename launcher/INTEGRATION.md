# Сборка APK: форк Zalith Launcher 2

## Почему Zalith 2, а не сам PojavLauncher

PojavLauncher закрыт и не обновляется. Minecraft 26.1.x требует Java 25 — её мобильная
сборка (Jre25) есть в Zalith Launcher 2, который работает на движке PojavLauncher
(тот же LWJGL/GLFW-мост, OpenAL, рендереры). Плюс в Zalith 2 уже есть джойстик в
раскладках. Лицензия Zalith 2 — GPL-3.0, значит и наш форк обязан быть открытым под GPL-3.0.

## Что меняем в форке (по шагам)

1. **Имя и пакет.** `applicationId` → `ru.mobilecraft.launcher`, `app_name` → «MobileCraft»,
   своя иконка. Без смены пакета APK встанет поверх настоящего Zalith.
2. **Ассеты.** Скопировать `overlay/assets/serverpack/` в `src/main/assets/serverpack/`
   модуля приложения, туда же — собранный `mobilecraft.jar` (CI делает это сам)
   и `default_layout.json` из CONTROLS.md.
3. **Код.** Скопировать `overlay/kotlin/ru/mobilecraft/pack/` в исходники приложения.
4. **Один экран вместо лаунчера.** Стартовый экран заменить на простой:
   поле «Ник» → кнопка «Играть» (никакого входа в Microsoft, см. раздел «Вход по нику»).
   По нажатию:
   - `ServerPackProvisioner(context, gameDir).provision()` в фоне с прогрессом;
   - затем штатный запуск Zalith для версии `provisioner.profileId`
     (`fabric-loader-0.19.2-26.1.2`). Установщик Zalith сам докачает ванильные
     файлы 26.1.2 по `inheritsFrom` и выберет Jre25.
   Список версий, установщик модлоадеров, загрузчик модов и модпаков — скрыть из UI.
5. **Микрофон.** В `AndroidManifest.xml`:
   ```xml
   <uses-permission android:name="android.permission.RECORD_AUDIO" />
   ```
   и запросить разрешение в рантайме перед первым запуском игры. Simple Voice Chat на
   Android-лаунчерах захватывает звук через OpenAL — без этого разрешения микрофон молчит.
6. **Раскладка по умолчанию.** При первом запуске копировать
   `assets/serverpack/default_layout.json` в папку раскладок Zalith и делать её активной.
7. **Рендерер по умолчанию.** Выставить рекомендуемый Zalith рендерер для новых версий
   (MobileGlues/Zink — что у них стоит по умолчанию для 26.1), Vulkan-движок не нужен:
   он появился только в 26.2.

## Вход по нику

Сервер в offline-режиме, поэтому Microsoft-аккаунт не нужен.

- Стартовый экран: одно поле «Ник» (проверка — `OfflineAccount.validate`) и кнопка
  «Играть». Ник сохраняется (`OfflineAccount.save`), при следующем запуске поле уже
  заполнено.
- В Zalith 2 есть локальные (офлайн) аккаунты. По кнопке «Играть» создаём/обновляем
  локальный аккаунт с этим ником и делаем его активным — дальше штатный запуск.
  Если в коде запуска нужно подставить данные напрямую, значения берутся из
  `OfflineAccount.launchArgs()` (ник, UUID в формате сервера, токен `0`, тип `legacy`).
- Экраны входа в Microsoft и проверку «сначала войдите в лицензию, потом можно локальный
  аккаунт» (если она есть в этой версии) из форка убрать.
- Ванильные файлы 26.1.2 лаунчер по-прежнему качает с серверов Mojang — для этого
  вход не нужен.
