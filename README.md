# MobileCraft — Android-клиент одного сервера

Лаунчер на движке PojavLauncher (через форк Zalith Launcher 2), в котором есть ровно одна
сборка: **Minecraft 26.1.2 + Fabric**, моды **Simple Voice Chat**, **Litematica** (+ MaLiLib)
и собственный мод **MobileCraft**, который подстраивает Java-клиент под телефон.

## Что внутри

```
mod/                      Fabric-мод MobileCraft (Java 25, маппинги Mojang)
launcher/overlay/         то, что добавляется в форк лаунчера
  assets/serverpack/      serverpack.json — адрес сервера, версии, список модов
  kotlin/.../pack/        установка Fabric + модов с Modrinth, запись servers.dat
launcher/CONTROLS.md      раскладка как в Bedrock
launcher/INTEGRATION.md   какие правки внести в форк Zalith 2
.github/workflows/        CI: собирает мод, затем APK
```

## Что делает мод MobileCraft

- **Чат меньше и сверху по центру**: ванильный чат переносится наверх по центру и
  уменьшается (`TopCenterChat`), по умолчанию 4–5 строк, узкий.
- **↻ Повтор последней команды** (кнопка → клавиша F13): отправляет последнюю `/команду`,
  запоминает её между запусками.
- **🎤 Микрофон-переключатель** (кнопка → F14): одно нажатие — включён, второе — выключен.
  Simple Voice Chat переводится в режим Push-To-Talk, мод «держит» его клавишу, пока
  микрофон включён. Возле чата мигает красное «MIC». При выходе с сервера микрофон гаснет.
- Мобильные настройки при первом запуске: автопрыжок, без паузы при сворачивании.

Управление (джойстик, прыжок, присед-переключатель, тап/удержание) делает лаунчер —
только у него есть мультитач. Схема — в `launcher/CONTROLS.md`.

## Что поменять под себя

Вход — просто по нику (`OfflineAccount.kt`): поле «Ник» и кнопка «Играть».

`launcher/overlay/assets/serverpack/serverpack.json` → `server.address` (сейчас заглушка
`play.example.ru:25565`) и `server.name`.

## Как собрать

1. Создай репозиторий на GitHub, загрузи туда этот проект.
2. Внеси правки из `launcher/INTEGRATION.md` в форк Zalith Launcher 2 (шаги 1, 4–7 — это
   правки в их коде: имя приложения, один экран «Играть», разрешение на микрофон).
3. Actions → Build MobileCraft → Run. Готовый APK будет в артефактах.

## Важно знать

- **Код не скомпилирован.** В этой среде нет доступа к сети, поэтому Gradle не смог
  скачать Minecraft 26.1.2 и Fabric. Первая сборка почти наверняка потребует поправить
  пару имён методов (в 26.1 Mojang и Fabric многое переименовали) — по ошибкам
  компилятора это быстро.
- **Что проверить на телефоне первым делом**: что Simple Voice Chat реагирует на
  удержание PTT через `KeyMapping.setDown` (если он опрашивает клавишу напрямую — нужен
  будет запасной путь через его клавишу «выключить микрофон»), и что клики по ссылкам в
  открытом чате попадают куда надо (чат сдвинут, кликабельные области у ванили остаются
  на старом месте).
- **Лицензии**: форк Zalith 2 — GPL-3.0, исходники APK нужно держать открытыми. Simple
  Voice Chat — All Rights Reserved, поэтому моды скачиваются с Modrinth при установке,
  а не вшиваются в APK. Файлы Minecraft качаются с серверов Mojang.
- **Вход по нику.** Раз сервер пускает по нику, любой может зайти под чужим ником.
  Поставь на сервер мод авторизации (например, EasyAuth для Fabric): игрок задаёт пароль
  `/register` и потом входит через `/login`. Для этого как раз пригодится кнопка повтора
  команды. Скины без лицензии стандартные; если нужны свои — серверный мод скинов
  (например, Fabric Tailor).
- Боссбар тоже сверху по центру — если на сервере он есть, увеличь `TOP_MARGIN` в
  `TopCenterChat`.
